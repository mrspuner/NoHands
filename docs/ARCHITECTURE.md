# Архитектура NoHands

**Дата:** 2026-09-02
**Состояние:** фаза 0 закрыта, фазы 1 и 2 не начаты

Документ описывает, как устроено приложение: что уже есть, что появится, и почему границы проведены именно так. Решения и их обоснования — в `DECISIONS.md`, замысел целиком — в `DESIGN.md`.

---

## 1. Что это

Менюбар-приложение для macOS, делающее две несвязанные вещи одним набором деталей:

- **Диктовка.** Зажал клавишу, наговорил, отпустил — текст появился в активном поле любого приложения
- **Созвоны.** Нажал «записать», провёл встречу, к утру получил размеченный markdown в `~/Meetings`

Общего у сценариев — распознавание речи. Всё остальное различается: источник звука, требования к задержке, объём, приватность.

---

## 2. Главное разделение: ожидание против фона

Вся архитектура держится на одном различии — **ждёте вы результата или нет**.

```
                    ЖДЁТЕ                         НЕ ЖДЁТЕ
                       │                              │
   ┌───────────────────┴──────────┐   ┌───────────────┴────────────────┐
   │  Диктовка                    │   │  Созвоны                       │
   │  бюджет задержки ~1 секунда  │   │  бюджет задержки — до утра     │
   │  20 часов речи в месяц       │   │  40–65 часов записей в месяц   │
   │  только ваш голос            │   │  чужие голоса тоже             │
   └──────────────────────────────┘   └────────────────────────────────┘
```

Из этого различия следует всё остальное: где считать, чем считать, что можно отдать наружу.

## 3. Поток диктовки

```
   ┌──────────┐
   │ клавиша  │  fn зажата
   │   fn     │────────────────┐
   └──────────┘                ▼
                    ┌─────────────────────┐
                    │  MicrophoneRecorder │  AVAudioEngine
                    │  16 кГц, моно, WAV  │  запись в буфер
                    └──────────┬──────────┘
                               │ fn отпущена
                               ▼
                    ┌─────────────────────┐
                    │ ParakeetTranscriber │  локально, Neural Engine
                    │      ~0,2 сек       │  модель 470 МБ в памяти
                    └──────────┬──────────┘
                               │ сырой текст
                               ▼
                    ┌─────────────────────┐
                    │   DeepSeek V4 Flash │  ЕДИНСТВЕННЫЙ выход наружу
                    │      ~2,2 сек       │  чистка: паразиты, пунктуация
                    └──────────┬──────────┘
                               │ чистый текст
                               ▼
                    ┌─────────────────────┐
                    │  NSPasteboard       │  подменяем буфер обмена,
                    │  + Cmd+V            │  шлём Cmd+V, возвращаем назад
                    └─────────────────────┘

   Суммарная задержка: ~2,4 сек  (заявлено в DESIGN.md ~1 сек — расхождение
   известно, решается в фазе 1)
```

**Почему чистка в облаке, а распознавание нет.** Локальная чистка на Qwen3 8B занимает 7,7 секунды против 2,2 у DeepSeek — при интерактивном сценарии это разница между «терпимо» и «невыносимо». Распознавание же локально быстрее облачного в четырнадцать раз, там выбор очевиден.

**Почему это не противоречит приватности.** В облако уходит только ваша собственная речь. Чужой в диктовке не бывает.

## 4. Поток созвонов

```
   ┌──────────┐
   │  кнопка  │  «начать запись»
   └────┬─────┘
        │
        ├──────────────────────────┬───────────────────────────┐
        ▼                          ▼                           │
   ┌─────────────────┐   ┌──────────────────┐                  │
   │ ScreenCaptureKit│   │ AVAudioEngine    │                  │
   │ системный звук  │   │ микрофон         │                  │
   │   → дорожка A   │   │   → дорожка B    │                  │
   │  (собеседники)  │   │      (я)         │                  │
   └────────┬────────┘   └─────────┬────────┘                  │
            │                      │            кнопка «стоп»  │
            └──────────┬───────────┘◄──────────────────────────┘
                       ▼
              ┌─────────────────┐
              │ очередь на диске│  ждёт ночи
              └────────┬────────┘
                       ▼
       ┌───────────────────────────────────┐
       │        ФОНОВЫЙ ВОРКЕР             │
       │                                   │
       │  дорожка A ──► диаризация         │  FluidAudio
       │              (кто когда говорил)  │
       │                                   │
       │  A и B ─────► Parakeet ──► слова  │  ~200× реального времени
       │                          с тайм-  │  71 минута за 21 секунду
       │                          кодами   │
       │                     │             │
       │                     ▼             │
       │           сопоставление сегментов │
       │           и слов по времени       │
       │                     │             │
       │                     ▼             │
       │              Qwen3 8B ──► конспект│  локально, MLX, ~2 минуты
       │                          и решения│
       └─────────────────┬─────────────────┘
                         ▼
              ~/Meetings/2026-09-01-название.md
                         │
                         ▼
              аудио → AAC 32 кбит/с
              лежит 7 дней, удаляется

   ВСЁ ЛОКАЛЬНО. Ни один байт чужой речи не покидает машину.
```

**Почему две дорожки, а не одна.** Своя дорожка с микрофона делает «меня» опознанным без всякой диаризации и без ошибок. Диаризация остаётся только на дорожке собеседников: на одного участника меньше в кластеризации и нет мест, где я говорю одновременно с кем-то.

**Почему конспекты локально, хотя чистка диктовки в облаке.** Здесь звучат чужие голоса. Участники давали согласие на запись, но не на передачу своих слов стороннему сервису — и спросить их задним числом невозможно.

## 6. Что написано на сегодня

```
   Package.swift
   │
   ├── Core/  (библиотека)
   │   │
   │   ├── Transcription/
   │   │     Transcriber.swift          протокол: файл → текст
   │   │     TranscriptionError.swift   шесть случаев отказа + languageNotSupported
   │   │     TranscriberChecks.swift    общие проверки: файл читается, текст не пуст
   │   │     ParakeetTranscriber.swift  локальный движок, актор     ◄── по умолчанию
   │   │     ScribeTranscriber.swift    облачный движок, актор      ◄── запасной
   │   │     MultipartBody.swift        сборка HTTP-запроса вручную
   │   │
   │   ├── Comparison/                  ТОЛЬКО ФАЗА 0
   │   │     ReferenceTranscript.swift  разбор чужой расшифровки
   │   │     TextNormalizer.swift       регистр, пунктуация, ё → е
   │   │     WordDiff.swift             пословное выравнивание
   │   │     ComparisonReport.swift     отчёт для чтения глазами
   │   │
   │   ├── Audio/
   │   │     AudioInputDevice.swift     опрос устройства через CoreAudio
   │   │     MicrophoneRecorder.swift   запись в WAV 16 кГц моно, актор
   │   │
   │   └── Secrets/
   │         Keychain.swift             чтение ключей, только чтение
   │
   ├── CLI/  (исполняемый файл nohands)
   │     NoHands.swift                  разбор команд, вывод, обработка ошибок
   │     TranscribeArguments.swift      разбор флагов команды transcribe
   │
   └── Tests/                           69 тестов
         CoreTests/                     всё, что не требует сети и моделей
         CLITests/                      разбор аргументов, предупреждения
```

**Протокол намеренно узкий:**

```swift
public protocol Transcriber: Sendable {
    func transcribe(audio url: URL) async throws -> String
}
```

Всё, что различается между движками — язык, словарь терминов, выбор модели — задаётся при создании конкретной реализации, а не лезет в общий интерфейс. Таймкоды в фазе 0 не нужны ни разу; они появятся в фазе 2, когда станет видно, в каком виде их удобно потреблять.

## 7. Зависимости

```
   NoHands
      │
      └── FluidAudio 0.14.8   ◄── ЕДИНСТВЕННАЯ внешняя зависимость
             │
             ├── Parakeet TDT v3   распознавание (используется)
             ├── диаризация        понадобится в фазе 2
             └── VAD               определение речи
```

Версия закреплена жёстко на 0.14.8. Свежие версии не устанавливаются: резолюция зависимостей намертво виснет на скачивании бинарного артефакта `NemoTextProcessing.xcframework` весом 47 МБ, нужного только для синтеза речи, которого проект не делает. Проверено трижды; тот же файл обычной загрузкой скачивается за секунды.

HTTP делается на `URLSession`, разбор аргументов — вручную. Ни то, ни другое не оправдывает новой зависимости.

## 8. Внешние сервисы

| Сервис | Зачем | Когда | Ключ |
|---|---|---|---|
| DeepSeek V4 Flash | чистка диктовки | фаза 1 | `nohands-deepseek` в Keychain |
| ElevenLabs Scribe v2 | запасное распознавание | не используется | `nohands-elevenlabs` в Keychain |

**Обязательное условие для DeepSeek:** параметр `thinking: {"type": "disabled"}` в каждом запросе. Без него модель уходит в рассуждения на четырнадцать тысяч символов, не доходит до ответа и тратит в тридцать пять раз больше выходных токенов — сорок центов в месяц превращаются в четырнадцать долларов.

## 9. Разрешения macOS

Три системных разрешения, каждое появляется в своей фазе — чтобы при поломке было понятно, что именно отвалилось.

```
   фаза 0  ──►  Микрофон              запись своей дорожки
   фаза 1  ──►  Универсальный доступ  перехват fn + вставка текста
   фаза 2  ──►  Запись экрана         системный звук через ScreenCaptureKit
```

Плюс одна ручная настройка перед фазой 1: действие клавиши fn в системных параметрах переключается на «ничего не делать», иначе macOS перехватит нажатие раньше приложения.

## 10. Состояние по фазам

```
   ФАЗА 0  ████████████████████  закрыта
           протокол, два движка, запись микрофона, сверка расшифровок,
           инструмент прогонов. 69 тестов

   ФАЗА 1  ░░░░░░░░░░░░░░░░░░░░  не начата
           Xcode-проект, менюбар, хоткей fn через CGEventTap,
           вставка текста, чистка через DeepSeek, индикатор в статус-баре

   ФАЗА 2  ░░░░░░░░░░░░░░░░░░░░  не начата
           ScreenCaptureKit, две дорожки, ночная очередь, диаризация,
           сопоставление таймкодов, генерация markdown, база отпечатков
```

**Что перейдёт из фазы 0 в приложение:** вся библиотека `Core` целиком. Xcode-проект подключит её как локальную зависимость — код останется на месте, переписывать не придётся.

**Что останется в фазе 0:** каталог `Comparison` и исполняемый `nohands`. Они существуют, чтобы измерять качество распознавания, и в приложении не нужны. Удалять их не стоит: при смене движка или модели сверка понадобится снова.
