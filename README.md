# NoHands

Менюбар-приложение для macOS: голосовой ввод текста по хоткею и автоматический архив расшифровок созвонов.

Личный проект, собран под одну конкретную машину. Не рассчитан на распространение — ни установщика, ни подписи, ни настроек по умолчанию для чужого окружения здесь нет.

## Как устроено

Диктовка идёт через облачный API, потому что нужна задержка около секунды. Созвоны расшифровываются локально на Apple Neural Engine, потому что их много и результат не срочен. Транскрипты складываются обычными markdown-файлами.

Подробнее — [docs/DESIGN.md](docs/DESIGN.md). Почему сделано именно так — [docs/DECISIONS.md](docs/DECISIONS.md).

## Требования

- macOS 14+, Apple Silicon
- Внешний микрофон (у Mac mini встроенного нет)
- Ключи ElevenLabs и Anthropic в Keychain
- В настройках клавиатуры действие клавиши fn переключено на «ничего не делать»
